Power — Commercial phase

One of the four on-site phase tabs on a commercial job card (Power, Lighting, Gear, Underground). Each one is the same simple record for that phase of the work, kept on the job so the office and the crew see the same thing.

What is on the tab

Status — Not started, In progress, Complete (stamped with who set it and when). Start and Complete dates. Notes for the phase. A Punch list sorted by building. Photos right on the phase.

Punch list by building

It works like the residential punch list, with buildings where the floors would be. Every tab starts with General for items that don't belong to one building. Tap + Add Building / Area to add one (Building A, Clubhouse, Site). Each building opens to its own items. Add areas inside it with + Area (Suite 101, Electrical room) when a building is big enough to split.

Items are the same as the residential punch: type and add, tap to mark done, assign to someone, flag as waiting, attach photos. The header on each building shows how many are open, waiting and assigned to you. Everything starts folded.

Buildings are set once per job. Add Building A on Power and it is also on Lighting and every Underground sub-tab, each with its own items. Rename and Remove are under each building. Remove takes the building off every tab, and it tells you how many open items go with it first.

The plan: build the list as we go on the first job or two, then turn the items we keep writing into a ready-made task list for the next job.

Where it does not go

These tabs are for the work on site. The pre-con paperwork (submittals, permits, gear release, site coordination) stays on the Job Start tab; long-lead gear tracking stays on Gear & Submittals.
