Homestead Electric — privacy

The Homestead Electric app is a private, internal tool used only by Homestead Electric employees to run our electrical jobs. It is not offered to the public.

Homestead Plan Intake is part of it. With the account owner's permission it reads that owner's Google Calendar, read-only, to find site walks and file the matching project plans into the company's own Google Drive. It does not change, delete or share calendar events, and it does not sell or pass Google user data to anyone. Data it reads stays in the company's own Google Cloud and Firebase project.

Access can be removed at any time at myaccount.google.com/permissions. Questions: koy@homesteadelectric.net.
