# Crew brief — App update v495 (2026-10-01)

App update v495. Pull down to refresh once and check Settings says v495. Two fixes on failed inspections and return trips, plus Koy's Appliance Loads amps tweak from v494.

EVERYONE (resi and commercial)
- Create Return Trip now tells you it worked (Koy's request): on the Rough or Finish tab, when a failed inspection has open items, tapping → Create Return Trip pops a toast with how many items went on the trip, and the button turns into a green "✓ On a return trip" chip. Tap it again and it just says the trip is already there instead of making a second one.
  Try: next failed inspection, type the items, tap Create once, watch for the toast and the green chip, then find the trip on the Return Trips tab.
- The inspection report opens on the return trip: the report PDF you attached on the Rough or Finish tab used to show up blank on the trip's card. It now shows as a file tile labelled "Final inspection report" (or "4-way"). Tap it and the PDF opens.
  Try: open a return trip made from a failed inspection, tap the report tile.
- Appliance Loads: set amps by hand (v494, Koy): on the Tools tab sheet you can type an amps value for an appliance instead of taking the guess.

FIXES
- Blank inspection report on return trips, see above.
- Double return trips from tapping Create more than once, see above.

REMOVED OR CHANGED
- Nothing removed. Upload the inspection report before you tap Create Return Trip. It's copied onto the trip at that moment, so a report added after goes on the trip's card directly.
