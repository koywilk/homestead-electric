APP UPDATE v599

Pull down to refresh and check Settings shows v599.

FIXED

- You can now mark an inspection failed more than once. When a rough or final inspection already shows failed, there's a new Failed again button next to Pass and Fail. It asks first, then logs another failure dated today and alerts the foreman.
  Try: on a job with a failed inspection, open the Rough or Finish tab and find Failed again. Only tap it if that inspection really failed again, because it can't be taken back.

- New failed items now reach the return trip. If you add failed items while the return trip from that inspection is still open, the green chip changes to Add to the return trip. Tap it and they go on the trip.

The Pass and Fail buttons work the same as before. No job data was changed by this update.
