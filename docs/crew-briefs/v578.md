RESIDENTIAL ONLY

- Rooms from FieldInk fill the punch list. Koy's request. When the plan's rooms have been sent over from FieldInk (the "Send rooms to Command Center" button on the plan), a floor header on the Rough or Finish punch list shows a "FieldInk rooms (N)" button while that floor is still missing some. Tap it, untick anything you don't want, tap Add. The rooms land as empty rooms on that floor on BOTH Rough and Finish in one go. Rooms already on the list are left alone; nothing gets renamed or removed. Greyed, unticked rows are names FieldInk has with nothing behind them (usually an old spelling), so leave those unless they're real. Hide drops a room from that list; "N hidden · Show" brings it back.
  Try: on a job whose plan has been sent from FieldInk, open Rough, Punch List, and look at the Main Level header. Tap FieldInk rooms, tap Add. Then check Finish: the same rooms are there.

- Rooms you type by hand show up on both lists. Type a room into "+ Room" on Rough and an empty room with that name appears under the same floor on Finish, and the other way round. If that name is already there it's skipped. Renaming or deleting a room still only changes the list you're on.
  Try: on any job, add a room on Rough, Main Level. Open Finish, Main Level. It's there, empty.

Nothing else changed in this one. Commercial jobs, QC walks and the old Legacy QC list are not affected.
