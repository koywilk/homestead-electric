NEW

- Home Runs: you can now send the list of home runs to someone (a GC, a supplier, the office) without making a panel schedule first. On the Home Runs tab, under By Panel / By Floor, use the SEND LIST bar: pick All panels or one panel, then tap PDF (printable list), CSV (spreadsheet) or Share (text or email it from your phone). Each run shows its load, floor, wire and breaker. It's made for customers, so it doesn't show what's pulled. Runs with no panel picked show under No Panel Assigned, so set panels first if the list is going out.
