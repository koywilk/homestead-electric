Punch List stage

A new board section between Finish In Progress and Completed. The app moves jobs in and out of it on its own. Foremen tap nothing new, and nothing gets written to the job.

The rule

Finish In ProgressCrew is working. Stays here below 90%, or at any % once nothing is left open.
→reaches 90%+ (or is marked Complete) with anything open
Punch ListFinish is basically done, but loose ends remain. The section shows what is still open.
→the last open thing closes
CompletedNothing open anywhere. Once the nightly sync is built, this is the only stage that shows Ready to Invoice in Simpro.

"Anything open" means any of these four. Each one counts the same way it already does elsewhere in the app:

Finish punchAny finish punch item not checked off. Voided items don't count.
QC itemsOpen items from a QC walk, same as the 100% gate already counts.
Failed finalFinal inspection failed and a failed item isn't marked fixed yet.
Return tripAny trip not marked Complete and not signed off.

Where it shows

Pipeline strip

A Punch List tile between Finish and Completed. Tapping it lists the jobs, like every other tile.

/dashboard

The active jobs list gets a Punch list stage with the same reason line. These jobs count as active, not done.

What stays the same

  • No new taps. No button or dropdown option. The crew works the punch list exactly as now.
  • Nothing written. No new field, no save, no rules or Cloud Function change. The section is worked out from what the job already has, so undoing it is just a code revert.
  • On Hold stays On Hold, even with open items.
  • The 100% gate is unchanged. Finish still can't be set to 100% while punch or QC items are open.
  • Quick jobs, temp peds, quotes and commercial jobs don't use Punch List.
  • Rough punch doesn't count. Punch List is only about finishing.
