Move punch items

A clickable mockup on the real open rough items for Stratton #959 and Brandt #1430. Nothing here touches the app. Tap Move items on the Rough punch list, pick where they go, pick the items, then look at the Finish and Return Trip tabs and the Job Board row.

How it works

  1. Move items shows on the Rough punch header whenever something is open. Nothing else on the list changes.
  2. Pick where they go: Finish punch list, a new return trip, or an open trip already on the job.
  3. Tick the items (or Select all) and tap Move. One Undo bar for ten seconds.

The record

  • To Finish: the item lands in the same floor and room on the Finish list, tagged From Rough · Koy · 11/16. On Rough it stays in place, greyed, tagged Moved to Finish · Koy · 11/16, and no longer counts as open, so the red chip drops.
  • To a return trip: it uses the link trips already have. The item stays on Rough tagged On Return Trip #3; checking it off on the trip checks it off here too. It still counts as open until it's done, because it is.
