# Goals Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Goals tab on `/dashboard` that shows the Team Goals sheet with live Simpro and dashboard numbers beside each goal, fed by one nightly read-only Simpro pull.

**Architecture:** A pure module `functions/goalsPull.js` (which jobs count, slim job, invoice stats) is driven by a scheduled function in `functions/index.js` that writes `settings/goalsSimpro`. In `src/App.js`, pure `odGoalsParse` / `odGoalsModel` sit just above `OfficeDash` (inside the test sandbox's extraction window) and a `tab === "goals"` branch renders them. Both pure layers have their own test in `scripts/`, wired into `prebuild`.

**Tech Stack:** Node 22 Cloud Functions (`firebase-functions/v1`), React in `src/App.js`, Firestore `settings/` doc, Google Sheets gviz CSV.

**Spec:** `docs/superpowers/specs/2026-10-23-goals-tab-design.md`

## Global Constraints

- Simpro is read-only; the only Firestore write is `settings/goalsSimpro` (existing read rule `settings/{docId}`); no rules, loader or job change.
- Counted job = `inv_pct ≥ 99.95` and costs posted (`nm_act !== 100` and mat/lab/hrs > 0). Weighted margin = Σ npl ÷ Σ contract. Credit = Simpro technician.
- A job with no Business Group is residential. No emojis in the UI. Fold everything but the mission and scoreboard cards.
- SW bump to `homestead-v562`; FEATURES.md entry tagged `SW v562`; guide `public/sops/dashboard.html` updated; crew brief `docs/crew-briefs/v562.md`.
- Pure dashboard code must live between `// ── Plan intake: Today → Plans card` and `function OfficeDash(` so `makeSandbox` extracts it.

## Review Focus

1. Sheet rows shift (a row inserted above REST OF 2026): parsing keys on header cells, never row numbers — Task 3 test "sections found by headers after an inserted row".
2. Sheet not shared / Google returns the HTML sign-in page: show the same "not shared for viewing" message as Appliance Loads, never a blank tab — Task 4 (same `/^\s*<(!doctype|html)/i` check).
3. `settings/goalsSimpro` missing (function not deployed yet): every Simpro card says "No Simpro pull yet" and the tab still renders the sheet — Task 3 test "no simpro doc".
4. An invoice with `DatePaid` before `DateIssued` or empty `Total`: excluded from days-to-paid, counted as open only when not paid — Task 1 test "bad dates".
5. A sheet BY cell like "Weekly, ongoing" or "Jan": no date → no flag; "Jan" → January next year when today is after June — Task 3 test "due flags".
